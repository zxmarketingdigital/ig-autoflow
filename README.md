# ZX Control — Semana 5: Automação Instagram

Setup oficial da Semana 5 do ZX Control. Transforma o seu Instagram numa máquina de atendimento automático, instalada direto no seu Claude Code.

## O que você terá no final

- Auto-resposta de comentários com envio de DM (Private Reply) por palavra-chave
- Agente de DM treinado nos seus próprios produtos
- Token do Instagram com refresh automático (60 dias)
- Rotina rodando na cadência que você escolher (comentários e DMs)
- Escalação para o seu WhatsApp pessoal quando o lead pedir um humano
- Mission Control 5.0 com widgets do Instagram
- Teste prático ao vivo validando que tudo funciona

## Pré-requisitos

- Python 3.9+ e git
- Claude Code
- Conta Instagram profissional e acesso ao app Meta Developers
- Não exige setup anterior: se você já tem outro setup instalado, ele aproveita o que estiver válido

## Instalação

```bash
gh repo clone zxmarketingdigital/ig-autoflow
cd ig-autoflow
claude
```

O Claude vai aguardar você digitar **`INICIAR SETUP SEMANA 5`** para começar. A partir daí o setup é guiado: 10 etapas, cada uma com explicação, execução e validação.
